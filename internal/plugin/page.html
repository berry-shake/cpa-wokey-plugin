CPA routing

                CPA settings that change how Wokey models are registered
              

              
            

            

              

              

                
                
routing:
  force-model-prefix: true

              

              

                How the prefix works
                
The prefix is the auth file's standard prefix field. CPA adds it to the registered model names and strips it before forwarding, so Wokey still receives the bare model ID.

                
An auth file without prefix uses the plugin's model-prefix; an empty prefix registers bare names for that key.

                
force-model-prefix is global: when it is on, every credential that has a prefix is registered only under the prefixed names.
